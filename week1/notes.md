# Week 1 — Linux, Git and Python

## Linux Commands Learned
- pwd: Show current directory
- ls: List files and directories
- cd: Change directory
- mkdir: Create a directory
- touch: Create an empty file
- cp: Copy files
- mv: Move or rename files
- rm: Delete files
- chmod +x: Make a file executable

## Git Commands Learned
- git status: Check repository status
- git add: Stage changes
- git commit: Save changes locally
- git push: Upload commits to GitHub
- git pull: Download and integrate remote changes
- git branch: Manage branches
- git switch: Change branches

## Python Concepts Learned
- Variables and data types
- If/else conditions
- For and while loops
- Functions
- Lists and dictionaries
- String manipulation
- Exception handling

## Something That Confused Me
I initially struggled to understand the purpose of try and except blocks, as they seemed somewhat unnecessary when I could simply write code that avoids errors in the first place. However, after experimenting with them, I realised that not all errors can be anticipated or prevented, particularly when dealing with user inputs or external systems. I now understand that try and except blocks allow a program to handle unexpected situations gracefully rather than crashing, which I can see being especially useful in robotics when working with sensors, hardware communication, and other unpredictable inputs.

## Reflection
This week was mainly a refresher rather than an introduction to Python and GitHub, as I've had previous experience with both. It was useful to revisit the fundamentals and strengthen my understanding before moving on to more advanced robotics programming.

One concept I found particularly useful was Python dictionaries. I can see them being valuable in robotics because they allow related information to be organised and accessed using meaningful names rather than numerical indices. For example, a dictionary could store the joint angles of a robotic arm, with keys such as base, shoulder, and elbow, making the code easier to read and maintain. I imagine this will become especially useful when working with multiple motors, sensors, and robot configurations.

Overall, this week helped reinforce my existing programming knowledge while giving me a better understanding of how these concepts can be applied to future robotics projects.
